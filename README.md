Pumperly for iOS is the iPhone app for [Pumperly](https://pumperly.com), the open-source fuel and EV route planner that finds the cheapest place to refuel along your route. It wraps the web app in a native SwiftUI shell and adds a "Cheapest nearby" home screen widget.

The app is in development. The first builds go to TestFlight, then to the App Store.
